# نظام داريو النصر الإخباري الآلي

خبر جديد في منبر النصر ← التقاط النص والصورة ← فلترة الإعلانات ← فحص التكرار بالمعنى ← إعادة الصياغة ← تصميم سنابة 1080×1920 بخط Arial Bold ← مراجعة آلية ← إرسال PNG غير مضغوط إلى محادثتك الخاصة ← النشر اليدوي في حساب N9rfc1.

النظام **لا ينشر على سناب شات أبدًا**.

## طريقة الوصول إلى القناة (مهم)

Telegram Bot API لا يقرأ منشورات قناة عامة إلا إذا كان البوت مشرفًا فيها، وقناة منبر النصر ليست قناتك. لذلك يدعم النظام طريقين مصرحين:

| الطريقة | ما تحتاجه | ملاحظات |
|---|---|---|
| `bot` (الأفضل لمالك القناة) | إضافة البوت مشرفًا في القناة بدون أي صلاحيات نشر، و `SOURCE_MODE=bot` | يصل كل منشور فور نشره بالدقة الكاملة مع الألبومات والتعديلات |
| `telethon` (موصى به) | حساب تيليجرام عضو في القناة + `TG_API_ID` و `TG_API_HASH` من my.telegram.org | واجهة MTProto الرسمية، صور بدقة كاملة، ألبومات كاملة، كشف تعديل المنشورات. قراءة فقط |
| `web` (احتياطي) | لا شيء | صفحة المعاينة العامة `t.me/s/n9rfc` التي يتيحها تيليجرام. صور أصغر دقة. يعمل تلقائيًا إن لم تُسجّل جلسة أو تعطلت |

البوت يُستخدم فقط للإرسال إليك واستقبال أوامرك.

## التشغيل خطوة بخطوة

1. أنشئ بوتًا من `@BotFather` وانسخ التوكن، ثم أرسل `/start` لبوتك.
2. انسخ `.env.example` إلى `.env` واملأ `BOT_TOKEN`.
3. اعرف رقم محادثتك: `python -m daryo.cli chatid` وضعه في `OWNER_CHAT_ID`.
4. (موصى به) من my.telegram.org أنشئ تطبيقًا وضع `TG_API_ID` و `TG_API_HASH`، ثم سجّل الدخول مرة واحدة:
   `python -m daryo.cli login` (يطلب رقم الجوال ورمز التحقق). يُفضّل حساب ثانوي منضم لقناة منبر النصر.
5. (موصى به) ضع `ANTHROPIC_API_KEY` لتحرير احترافي وكشف تكرار بالمعنى. بدونه يعمل محرر محلي محافظ يقتبس من النص حرفيًا.
6. ضع الشعار الأصلي في `assets/logo.png` (PNG بخلفية شفافة). حتى ذلك يُستخدم شعار نصي مؤقت.
7. افحص كل شيء: `python -m daryo.cli check`
8. شغّل الخدمة المستمرة:

**Docker (الأسهل):**
```bash
docker compose build
docker compose run --rm daryo python -m daryo.cli login   # مرة واحدة إن اخترت telethon
docker compose up -d
docker compose logs -f
```

**أو systemd على خادم Linux:** راجع `deploy/daryo-alnasr.service`.

الخدمة تعيد التشغيل تلقائيًا بعد أي عطل أو إعادة تشغيل للخادم، وتعمل دون أي لوحة تحكم مفتوحة.

## التشغيل على جهازك الشخصي (بدون خادم)

النظام يعمل ما دام الجهاز شغالًا ومتصلًا بالإنترنت. عطّل وضع السكون أو اجعله طويلًا.

**ويندوز:**
1. ثبّت Python 3.12 من python.org (فعّل خيار Add Python to PATH).
2. فك الضغط في مجلد ثابت، مثل `C:\daryo-alnasr`.
3. انقر مرتين على `start-windows.bat`. بعد دقيقة تقريبًا يوصلك في تيليجرام: 🟢 بدأ نظام داريو النصر.
4. للتشغيل التلقائي مع كل تسجيل دخول، انقر مرتين على `autostart-windows.bat` مرة واحدة.
5. اختياري، لربط حساب تيليجرام: افتح موجه الأوامر داخل المجلد واكتب `start-windows.bat login`.

**ماك:**
1. ثبّت Python 3.12 من python.org.
2. فك الضغط في مجلد ثابت، ثم افتح Terminal داخله.
3. للتشغيل الآن ومع كل تسجيل دخول: `bash autostart-mac.sh` (السجل في `data/service.log`).
4. اختياري: `bash start-mac.sh login`.

## التحكم من تيليجرام (من محادثتك فقط)

| الأمر | الوظيفة |
|---|---|
| `/on` و `/off` | تشغيل وإيقاف يدوي |
| `/hours 08:00-02:00` | ساعات التشغيل بتوقيت الرياض (تدعم تجاوز منتصف الليل وعدة فترات بفاصلة) |
| `/hours 24` | طوال اليوم |
| `/status` | الحالة وإحصائيات آخر 24 ساعة |
| `/now` | فحص فوري |
| `/last` | آخر 10 منشورات وما حدث لكل منها |
| `/test` | سنابة تجريبية |

نفس التحكم متاح من الخادم: `python -m daryo.cli on|off|status|hours 08:00-02:00`.

## القوالب

خمسة قوالب بهوية موحدة (خلفية بيضاء بعلامة مائية خفيفة، شعار أعلى اليمين، شريط حقوق أحمر يحمل N9rfc1):
عاجل (شريط أحمر كبير)، تصريح، بالأرقام (رقم ضخم)، سوق الانتقالات، أخبار عامة، وقالب نصي احترافي عند غياب صورة صالحة.
شارة **تحديث** للأخبار المحدثة وشارة **غير رسمي** للتسريبات والتقارير.

لتوليد النماذج: `python -m daryo.cli samples`

## ضمانات الجودة

- الخط: يُرفض التصميم إن لم يطابق ملف الخط بصمة Arial Bold المعتمد. لا يوجد أي خط بديل.
- كل حرف يُفحص بوجوده في الخط قبل الرسم، والإيموجي تُحذف.
- فحص الهوامش الآمنة لواجهة سناب، والتداخل بين العناصر، وتجاوز النص، وتكبير الصورة المفرط، والمقاس 1080×1920.
- الصورة الأصلية توضع كاملة دون قص أو تشويه أو توليد أو تعديل.
- حواجز تحريرية: أي رقم غير موجود في المصدر يُرفض، ولا يوصف خبر بالرسمي إن لم يذكر المصدر ذلك.
- عند فشل التصميم أو التحرير أو الإرسال: لا تُرسل صورة ناقصة، بل تنبيه واضح مع رابط المنشور.
- تنبيه عند تعذر قراءة المصدر 3 مرات متتالية ورسالة عند عودته.
